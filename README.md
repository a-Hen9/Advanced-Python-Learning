# Python 进阶学习指南

> 一份面向"已会基础语法，想写出真正 Pythonic、工程化代码"的学习者的系统进阶资料。
> 全部示例基于 **Python 3.10+** 验证（绝大多数兼容 3.8+，仅 3.11/3.12 才有的特性会单独标注版本）。

---

## 一、适用人群与前置要求

**适用人群**：已经掌握 Python 基础语法（变量、分支、循环、函数、类、列表字典等），能写出可运行的脚本，但遇到过下面这些困惑的读者：

- 看不懂别人的代码里 `@xxx` 的"魔法"（装饰器）
- 搞不清 `for` 循环背后到底发生了什么（迭代协议）
- 听说过 GIL，但说不清多线程到底有没有用
- 想处理大文件、大量数据，却总是把内存撑爆
- 写的代码能跑，但"不工程"：没有类型注解、没有测试、依赖一团乱

**前置要求**：

1. 安装 Python 3.10 或更高版本（推荐 3.12+），命令行输入 `python --version` 能正常输出版本号。
2. 会使用 pip 安装第三方库。
3. 最好有一款支持 Python 的编辑器/IDE（VS Code + Python 扩展、PyCharm 均可），**支持点击跳转定义**——进阶学习最重要的方法之一就是"跳进源码看实现"。

## 三、如何使用本资料

1. **动手运行每一份示例代码**。所有示例都是完整可运行的（除非注释说明"危险示例，仅演示"）。新建 `demo.py` 粘贴运行，观察输出，再改一改参数看变化。
2. **每章末尾附有练习题**，做不出来再回看正文；练习的意义在于暴露"以为懂了其实没懂"的部分。
3. **善用交互式解释器**：`python -i demo.py` 可以在脚本跑完后继续交互，随时检查对象的 `__closure__`、`__dict__` 等属性。
4. **遇到内置函数/模块先查官方文档**：<https://docs.python.org/zh-cn/3/>（有中文版），养成读一手资料的习惯。

## 四、每章统一结构

- **本章目标**：学完后你应该能做到什么
- **概念与原理**：不止会写，还要能解释为什么
- **实战案例**：贴近真实开发的完整代码
- **常见陷阱**：进阶路上最容易踩的坑
- **本章小结 + 练习**：自测用

## 五、运行环境说明

```bash
# 建议先创建虚拟环境（工程化规范的第一次实践，详见第 09 章）
python -m venv .venv

# Windows PowerShell
.venv\Scripts\Activate.ps1
# Windows Git Bash
source .venv/Scripts/activate
# Linux / macOS
source .venv/bin/activate

# 部分章节示例需要的第三方库（用到时再装即可）
pip install httpx        # 第 07 章异步 HTTP 示例
pip install pytest ruff mypy  # 第 09 章工程化示例
```

> 同目录下的 `Python进阶学习指南.html` 是全部章节的合并阅读版，带目录导航和代码高亮，双击用浏览器打开即可。
